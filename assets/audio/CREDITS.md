# Audio credits

These clips ship with the silt mud demo. Each one is a recorded sound,
trimmed and converted to mono 22050 Hz 16-bit PCM. Nothing here is a
synthesized oscillator. Levels were matched, a few milliseconds of fade
were added at edit points, and the loops were overlapped so they repeat
without a click.

https://creativecommons.org/publicdomain/zero/1.0/

Pack: "The Dyno Sessions: 190E".
https://freesound.org/people/Chippy569/packs/9658/

A Mercedes-Benz 190E 16V on a dyno, microphone an Audix D6 about one
foot behind the exhaust. The files below are trims of the Freesound
preview of each CC0 recording. The original uploads are 96 kHz 24-bit
WAV and need a logged-in download; the preview is the copy that can be
fetched and redistributed with the demo.

The mud clips are recordings of someone working mud by hand, not a tire
on a track. They are the CC0 mud recordings that could be shipped, and
the tire layer loops them while a wheel is in the wet.

## Libraries checked and not shipped

Kenney Impact Sounds is CC0 (https://kenney.nl/assets/impact-sounds).
Those files are designed game impacts. The recorded mud hits above fit
the clump, splash, and puddle better, so no Kenney file is included.

The Sonniss GDC game-audio bundles are royalty-free for a finished
game, film, or interactive project. The license does not allow
redistributing the sound effects as files, including inside a public
source repository. This demo is a public git repo, so none of those
files are included. https://sonniss.com/gdc-bundle-license/
